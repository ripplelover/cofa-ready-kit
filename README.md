# Cofa Ready Kit

**내일은 제공 Codex에 아래 시작 요청을 한 번 보내고, 결과를 확인하며 진행하세요.**

SK하이닉스 AI 해커톤 2026 2차 예선을 위한 비공식 준비 도구입니다. 실제 문제·정답·채점표는 포함하지 않습니다. 개인 안내 기준 **10월 31일 10:00–14:00, 09:40까지 접속 준비**, 과제 최대 180분과 후속 서술형 6문항×5분입니다. 당일 공지와 실제 과제 안내가 우선합니다.

## 1. Cofa에서 제공 Codex를 여세요

웹캠·휴대폰 Proctor·화면 공유·신분 확인을 안내대로 마칩니다. 화면 아래에 이미 **OpenAI Codex / Ask Codex**가 보이면 그곳이 AI 입력란입니다. 일반 터미널만 있으면 `codex`를 입력해 엽니다. `/model`에서 실제 제공된 허용 모델을 확인합니다. 안내된 Sol 6.1이 있으면 시작점으로 사용할 수 있습니다. 개인 계정 로그인이나 API 키를 추가하지 않습니다.

신분증·안경 확인은 **과제 시작으로 녹화가 시작된 뒤** 화면과 Proctor 가이드의 순서에 따릅니다.

## 2. AI 입력란에 이것만 보내세요

**과제 제출 확정 전용 요청입니다.** 일반 셸에 붙여 넣는 명령이 아닙니다. 시험 중에는 이 외부 채팅에 문제나 파일을 보내지 말고, Cofa 제공 Codex에서 진행합니다.

```text
아직 과제 제출 확정 전이야. 현재 작업 위치와 실제 과제 안내부터 확인해 줘.
공개 준비 키트 https://github.com/ripplelover/cofa-ready-kit.git 를
실제 과제 폴더 아래 .cofa-kit에 git clone --depth 1로 받아 줘.
이미 그 폴더가 있으면 삭제·덮어쓰기·초기화하지 말고 내용부터 확인해 줘.
받은 .cofa-kit/prompts/SCENARIO.md를 읽고 현재 과제를 진행해 줘.
키트의 README와 examples는 실제 시험 문제가 아니야.
키트를 받거나 읽을 수 없으면 원인을 밝히고 실제 과제 자료로 가능한 일을 진행해 줘.
먼저 실제 요구사항·필수 제출물·내가 확인할 업무 질문을 짧게 정리해 줘.
화면 조작과 제출은 내가 직접 할게. 제출 확정 후에는 AI 작업을 중단해 줘.
```

Codex가 명령 실행 승인을 표시하면 **명령과 경로를 읽고** 공개 키트 다운로드 등 요청한 작업인지 확인합니다. 첫 결과에서 **실제 과제 안내 경로, 필수조건, 중요한 질문**을 확인하세요. 읽지 못했는데 읽었다고 하거나 테스트 없이 성공이라고 하면 그대로 진행하지 않습니다.

**스킬 설치·MCP 연결은 시작에 필수가 아닙니다.** 기본 흐름은 Codex가 필요한 `SKILL.md` 파일을 직접 읽습니다. 스킬 목록 등록을 원할 때만 설치기를 사용하고, MCP는 실제 필요할 때만 연결합니다.

## 3. 같은 대화에서 확인하며 이어가세요

| 상황 | Codex에 보낼 말 / 본인이 할 일 |
| --- | --- |
| 업무 질문이 생김 | 오른쪽 실무자 에이전트에 직접 질문 → 받은 답을 Codex에 전달 |
| 요구사항이 정리됨 | `확인된 조건부터 구현하고 관련 검증까지 진행해 줘. 변경 파일·실제 결과·내가 할 일만 짧게 알려 줘.` |
| 수정이 끝남 | `실제 요구사항과 대조해 정상·오류·경계 사례를 확인해 줘. 실패·미검증·필수 누락을 구분해 줘.` |
| 시간이 줄어듦 | `화면의 남은 시간은 __분이야. 필수 오류와 제출 준비를 우선해 줘.` — 실제 숫자를 입력 |
| 제출 준비 | `실제 필수 문서를 구현·검증 기록에 맞춰 정리하고, 내가 설명해야 할 선택·근거·한계를 짚어 줘.` |

**작업 종료 10분 전부터** 본인이 저장·필수 파일·제출 화면을 확인합니다. 제출 확정 뒤 AI·Skill·MCP 사용을 중단하고, 서술형은 **AI와 복사/붙여넣기 없이 직접** 답합니다. 업로드 후 완료 화면의 제출 ID·시각·파일 수·크기까지 확인해야 끝납니다.

더 자세한 화면 위치·시간표·막혔을 때 조치는 **[당일 사용법 한 장](docs/EXAM-PLAYBOOK.md)**에 있습니다. 아래 문서를 처음부터 전부 읽을 필요는 없습니다.

현재 도구 버전은 **1.2.1**입니다. 스킬은 문제 파악(`cofa-triage`), 구현(`cofa-build`), 검증(`cofa-verify`), 제출 **확정 전** 설명 연습(`cofa-explain`), 반도체 분석(`cofa-semiconductor`)의 5개입니다. 이름 5개를 외우거나 한꺼번에 호출할 필요가 없습니다.

로컬 MCP 도구도 5개이며 파일 구조 확인·CSV 요약·가중 검사 통과율·I-MR 신호·CSV 키 관계 검사를 제공합니다. 동일 기능을 Python 3.10+ CLI로 실행할 수 있고 API 키·추가 AI 구독·원격 MCP가 필요하지 않습니다. 실제 프로젝트의 테스트는 그 프로젝트의 언어와 기존 실행법을 따릅니다.

`doctor`는 실행 환경 확인, `check`는 파일·선언 구조 확인입니다. 둘 다 과제 정확성이나 합격을 보장하지 않습니다. 공개 데모의 주문 API와 이 키트의 반도체 예제도 내일 출제 예고가 아닙니다. **실제 Cofa 환경의 파일 작업·스킬 탐색·MCP 연결은 사전 체험에서 확인해야 합니다.**
