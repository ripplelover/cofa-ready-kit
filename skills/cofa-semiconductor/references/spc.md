# 설비 시계열: I-MR 계산과 해석 범위

I-MR은 한 번에 하나씩 관측된 연속 측정값을 살피는 방식이다. 양품 비율·결함 건수에 편의상 적용하지 않는다. 먼저 측정량·단위·장비·챔버·제품·recipe·공정 구간을 확인하고 비교 가능한 한 계열을 만든다.

## 먼저 확인할 데이터 조건

- 시간순서와 시간대, 같은 시각의 순서 번호, 샘플링 간격을 확인한다. 파일 행 순서가 시간순서라는 가정은 피한다.
- 정비·recipe 변경·센서 교정·설비 재가동 전후를 구분한다. 무조건 하나의 기준기간으로 묶지 않는다.
- 결측값을 제거하면 떨어진 두 관측이 인접하게 된다. 긴 공백을 가로질러 MR을 계산할지 먼저 정한다. 0 채우기·평균 보완으로 변화량을 숨기지 않는다.
- 기준기간은 미래 감시 구간을 보기 전에 정한다. 감시값을 포함해 한계를 다시 맞추면 찾으려던 변화가 한계 안에 흡수될 수 있다.
- 과거 기준도 정상이라고 자동 가정하지 않는다. 기준 구간의 특이점은 원인을 조사하고, 제외 사유를 남긴다. 경보를 없애기 위한 삭제는 하지 않는다.

NIST는 관리한계와 규격한계를 구분하고, 적은 자료로 추정한 한계의 성질이 이론과 다를 수 있음을 설명한다. 관리한계는 변동을 살피는 기준이며 실제 제품의 합격 규격을 대신하지 않는다. [NIST Variables Control Charts](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc32.htm)

## 최소 수식과 손계산

기준기간의 시간순 관측을 `x1 ... xn`이라고 할 때:

```text
MR_i = abs(x_i - x_(i-1)), i = 2 ... n
MRbar = sum(MR_i) / (n - 1)
sigma_hat = MRbar / 1.128
I 중심선 = mean(x)
I 하한/상한 = mean(x) ± 3 * sigma_hat
MR 중심선 = MRbar
MR 하한 = 0
MR 상한 = 3.267 * MRbar
```

I 수식의 근거는 [NIST Individuals Control Charts](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc322.htm)다. MR 상수는 [NIST Student's SEMSTAT, 인쇄 p.68·PDF 69번째 페이지](https://www.itl.nist.gov/div898/handbook/semstat/semstat-doc.pdf#page=69)에서 확인했다. 표시에 반올림한 값으로 판정을 다시 계산하지 않는다.

가상 계산 확인: 기준값이 `10, 11, 10, 11`이면 평균 `10.5`, MR은 `1, 1, 1`, MRbar는 `1`이다. I 한계는 약 `7.8404255 ... 13.1595745`, MR 상한은 `3.267`이다. 이후 값 `15`는 I 상한을 넘고 직전 `11`과의 차이 `4`도 MR 상한을 넘는다. **이 짧고 인위적인 배열은 수식을 확인할 뿐 공정 안정성을 입증하지 않는다.**

수식상 MR에는 두 관측이 필요하다. 이것이 안정성 판단을 위한 충분한 표본이라는 뜻은 아니다. 키트의 입력 최소 개수·표본 경고는 프로그램의 제한과 교육용 안내이며 통계적 인증 기준이 아니다. MRbar가 0이면 변동 추정이 퇴화하므로 “완전 정상”으로 결론내리지 않는다. 측정 해상도·반올림·상수값 수집 오류도 확인한다.

## 결과가 말하는 것과 말하지 않는 것

| 결과 | 가능한 보고 | 단정하지 않을 것 |
| --- | --- | --- |
| I 한계 이탈 | 기준 구간 대비 관측 수준의 변화 신호 | 제품 불량 확정, 특정 설비가 원인 |
| MR 한계 이탈 | 인접 관측 사이 큰 변화 신호 | 반드시 품질 문제, recipe를 즉시 바꿔야 함 |
| 이탈 없음 | 적용한 규칙에서 이탈을 찾지 못함 | 공정 안정성·독립성·정규성 입증 |
| 변동 추정 0 또는 근거 부족 | 한계 해석 제한·추가 측정 필요 | 능력 무한대, 불량 위험 0 |

단일 3σ 이탈 검사만 수행했다면 run/trend 등 다른 규칙까지 확인했다고 쓰지 않는다. 경계와 같은 값의 판정은 구현 규칙을 명시한다. 기존 현장 관리한계·규격·반응 절차가 제공되었다면 그 출처와 버전을 보존한다.

촘촘한 센서 데이터의 인접값은 서로 관련될 수 있다. NIST는 시계열의 독립적인 변동 가정을 확인할 때 자기상관을 살피며, 가정이 맞지 않으면 다른 모델을 고려하도록 설명한다. 키트의 I-MR 계산은 자기상관·분포 적합성을 자동 검증하지 않는다. [NIST Autocorrelation](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35c.htm)

## 공정능력 요청이 들어왔을 때

Cp/Cpk를 계산하기 전에 실제 LSL/USL의 출처·단위·적용 제품을 확인한다. 안정성, 대표성, 독립성 및 사용 식의 분포 조건도 확인한다. NIST의 표준 Cp/Cpk 식은 안정된 공정과 정규분포 맥락을 전제로 한다. 표본 개수만 채웠다고 조건이 충족되는 것은 아니다. [NIST Process Capability](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm)

규격이 없으면 임의로 평균±3σ를 규격으로 정해 Cpk를 만들지 않는다. 단측 규격에 가짜 반대편 한계를 추가하지 않는다. 계산에 사용한 산포 추정이 무엇인지 설명하며, 작은 표본·비정규·혼합 공정이라면 숫자 하나로 적합 판정을 내리지 않는다. 이 키트는 Cp/Cpk 자동 판정을 제공하지 않는다.

## 구현 확인 목록

단일 계열, 증가하는 시각, 결측·동일시각 정책, 기준기간 고정, 기준→감시 경계의 MR 연결, 감시값 추가 시 기존 한계 불변, 상수열, 최소 입력 미달을 확인한다. 위 손계산과 프로그램 값을 대조한다. 분석 결과는 담당자의 추가 조사 목록으로 남기며 설비 제어·정비 명령·lot 해제로 연결하지 않는다.
