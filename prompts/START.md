# 과제 시작 때

[시험 첫 화면](../README.md) · [전체 문서 지도](../docs/INDEX.md)

제공된 Codex에서 사용한다. 스킬이 목록에 없다면 아래의 실제 파일 경로를 AI에게 읽도록 지정해도 된다. 설치 경로가 다르면 경로만 바꾼다. 이 프롬프트를 보내기 전에 실제 과제 폴더에 있는지 확인한다.

```text
$cofa-triage 를 사용해 이 작업 폴더의 README, 과제 안내, 제공 자료를 읽어줘.
스킬이 검색되지 않으면 준비 키트의 skills/cofa-triage/SKILL.md를 직접 읽어줘.

과제의 사용자가 해야 할 일, 필수 제출물·경로, 성공 조건과 제약을 정리해줘.
명시된 요구사항과 네 가정을 구분하고 근거 파일 위치를 붙여줘.
아직 실제 과제에 없는 기능이나 배점을 만들어내지 마.
실무자에게 확인하면 구현이 달라질 질문만 우선순위대로 짧게 만들어줘.
질문은 내가 플랫폼에서 직접 전달할게. 답을 기다리는 동안 가능한 점검은 진행해줘.

남은 시간을 고려해 가장 작은 완결된 흐름과 확인 방법을 제안하고,
확정된 부분부터 구현에 착수해줘. 필수조건이 충돌하면 그 부분만 먼저 알려줘.
과제 자료를 외부에 보내거나 외부 AI·API 키·Git Push·Computer Use를 사용하지 마.
```

첫 답을 읽을 때 제출물·경로와 핵심 요구가 맞는지 본인이 확인한다. AI의 잘못된 문제 정의를 그대로 두고 구현 속도만 올리지 않는다.
