# 대화가 길어졌거나 작업을 재개할 때

[시험 첫 화면](../README.md) · [전체 문서 지도](../docs/INDEX.md)

제출 확정 전에만 사용한다. 확정 후 질문 준비 대기·서술형 단계에서는 AI 작업을 재개하지 않는다.

```text
새 설계를 시작하지 말고 현재 작업을 이어가줘.
실제 과제 README와 제출 요구사항, 현재 변경 파일, 결정 기록, 검증 결과를 읽어줘.
키트의 README와 예제를 실제 과제로 취급하지 마.
현재 남은 시간은 내가 응시 화면에서 확인한 값을 따르자.

1. 이미 완료되고 검증된 필수조건
2. 구현됐지만 아직 검증되지 않은 조건
3. 남은 실패·불확실성·제출 파일
4. 바로 실행할 다음 행동

위 네 가지만 짧게 정리하고 다음 행동을 수행해줘.
기록과 코드가 다르면 코드를 확인한 뒤 차이를 밝혀줘.
이전 세션에서 성공했을 것이라고 추정해 검증 기록을 채우지 마.
```

재접속은 시험 시간을 초기화하거나 정지시키지 않는다. 응시 화면에 표시된 남은 시간을 함께 알려주면 범위를 줄이기 쉽다.
