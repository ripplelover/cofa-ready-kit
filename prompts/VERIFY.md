# 제출 확정 전에

[시험 첫 화면](../README.md) · [전체 문서 지도](../docs/INDEX.md)

이 요청은 제출 확정 전에만 사용한다. 확정 후 질문 준비 대기·후속 서술형 단계에서는 사용하지 않는다.

```text
$cofa-verify 로 제출 전 점검해줘.
스킬이 없거나 예전 설치본이면 .cofa-kit/skills/cofa-verify/SKILL.md를 직접 읽어줘.

실제 과제 안내의 필수 파일·경로·요구사항을 현재 결과물과 비교해줘.
기존 성공 설명을 그대로 믿지 말고 중요한 결과를 실행 증거로 확인해줘.
기대값은 실제 요구나 독립된 작은 계산에서 정하고, 수정 전후에 같은 입력·기준으로 비교해줘.
필수조건 실패·실행 불가·틀린 결과부터 남은 시간 안에 최소한으로 고쳐줘.
확인됨 / 실패 / 미확인을 구분하고 근거 파일·실행 결과를 남겨줘.
내가 직접 Browser에서 확인할 핵심 동작이 있다면 짧은 순서로 알려줘.
제출 문서와 실제 구현·검증이 일치하는지도 확인해줘.
제출 버튼은 내가 직접 누를게.
```

작업 종료 10분 전에는 저장 상태와 필수 경로를 확인하고 제출 절차에 들어간다. 미리보기 목록이 제출 파일 전체를 나타내는 것은 아니다. 제출물 확정 후에는 파일을 수정할 수 없다.
