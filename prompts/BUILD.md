# 구현을 맡길 때

먼저 과제의 실제 요구와 남은 시간을 확인한 뒤 사용한다. 아래 문장은 기능을 사전에 정하지 않으며 현재 작업 기록을 기준으로 이어간다.

```text
$cofa-build 를 사용해 현재 요구사항과 작업 기록을 기준으로 이어서 구현해줘.
스킬이 없으면 준비 키트의 skills/cofa-build/SKILL.md를 읽어줘.

지금 가장 중요한 미충족 필수조건 하나를 먼저 끝내줘.
기존 스택과 실행 방식을 유지하고 입력부터 결과까지 실제로 연결해줘.
완료 후 해당 조건의 확인 방법을 실행하고 실제 결과·남은 한계를 알려줘.
중요한 선택 이유와 외부에서 참고한 부분은 작업 기록에 짧게 남겨줘.
검증이 끝난 필수조건부터 다음으로 넘어가고 제출 준비 시간도 남겨줘.
```

한 번에 큰 작업을 맡겼다면 중간 산출물을 확인한다. 승인 대기, 실행 중, 완료를 구분하며 같은 명령을 반복 전송하지 않는다.
