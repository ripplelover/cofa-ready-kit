# 실제 예측 모델 과제일 때

[시험 첫 화면](../README.md) · [전체 문서 지도](../docs/INDEX.md)

표·시계열 자료로 분류·회귀 모델을 학습하거나 평가해야 할 때만 사용한다. 단순 통계·검사 통과율·SPC·API 오류 수정이면 이 요청을 추가하지 않는다. 제출 확정 후 질문 준비 대기·후속 서술형에서는 사용하지 않는다.

**제공 Codex 입력란**에 보낼 요청:

```text
$cofa-model-eval 을 사용해 실제 과제의 예측 모델 학습·평가를 진행해 줘.
스킬이 없거나 예전 설치본이면 .cofa-kit/skills/cofa-model-eval/SKILL.md를 직접 읽어 줘.
예측 시점·라벨·단위·그때 알 수 있는 특징·업무 기준부터 실제 자료에서 확인해 줘.
미확인 업무 조건은 질문으로 남기고, 시간·그룹·동일 개체 누수를 막는 분할을 정해 줘.
기존 언어와 의존성으로 단순 기준선을 먼저 만들고 같은 행·지표로 후보를 비교해 줘.
전처리는 학습 부분에만 적합하고 임계값은 검증 자료에서 정해 줘.
최종 테스트는 선택에 쓰지 말고, 실제 실행 결과·평가 개수·작은 표본의 한계를 남겨 줘.
남은 시간 안에 범위를 줄이고 하지 않은 학습·측정은 성공으로 기록하지 마.
```

`.cofa-kit`이 다른 위치에 있으면 실제 경로로 바꾼다. 이 요청은 특정 모델·라이브러리·파일명·성능을 미리 정하지 않는다. 설치나 MCP 연결 없이 파일의 지침을 읽는 방식으로도 사용할 수 있다.
