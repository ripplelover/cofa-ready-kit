# 본인이 설명하는 연습

시험 전 또는 과제 제출물 확정 전에만 사용한다. **실제 후속 서술형에서는 AI를 사용하지 않는다.** 아래는 출제 예상 문항이나 정답이 아니라, 자신의 작업을 이해했는지 확인하는 연습이다.

```text
$cofa-explain 으로 설명 연습을 하자. 지금은 제출 확정 전 연습 단계야.
스킬이 없으면 준비 키트의 skills/cofa-explain/SKILL.md를 직접 읽어줘.
실제 파일과 기록에서 중요한 선택을 골라 한 번에 한 질문만 해줘.
내가 먼저 답할 때까지 모범답안이나 문장 초안을 쓰지 마.
답한 뒤에는 사실과 다른 부분, 빠진 판단 근거, 확인하지 않은 주장을 짚어줘.
내 말로 다시 설명해 볼게.
```

혼자 연습할 때는 다음 중 실제 작업에 해당하는 질문을 고른다. 각 질문에 5분 이내로 직접 써 보고, 준비 단계에서만 파일과 대조한다.

1. 해결하려던 사용자의 문제는 무엇이며, 요구사항 중 무엇을 가장 먼저 충족했는가? 그 순서를 선택한 근거는 무엇인가?
2. 가장 중요한 설계 선택 하나를 설명하라. 검토한 대안과 그 대안을 택하지 않은 이유는 무엇인가?
3. 실제 입력 하나가 최종 결과로 바뀌는 과정을 설명하라. 잘못되거나 비어 있는 입력은 어느 단계에서 어떻게 처리되는가?
4. AI의 제안 중 검토 후 수정하거나 받아들이지 않은 것은 무엇인가? 실제로 그런 사례가 없다면 AI가 만든 결과를 어떻게 검증했는가?
5. 핵심 결과가 맞다는 근거는 무엇인가? 실행한 확인 방법 하나, 그 결과, 그 방법만으로는 보장하지 못하는 범위를 설명하라.
6. 남아 있는 한계 중 사용자에게 가장 큰 영향을 주는 것은 무엇인가? 시간이 더 있다면 어떤 근거를 수집하고 무엇부터 개선하겠는가?

답변에는 실제 한 일만 적는다. 측정하지 않은 성능 향상이나 하지 않은 협업을 꾸미지 않는다. 구현하지 않은 기능이 질문의 전제에 들어 있으면 차이를 밝히고 자신의 결과를 설명한다. 자신의 선택과 한계를 정확히 설명하는 편이 외운 범용 문장을 늘어놓는 것보다 도움이 된다.

운영 기준: 「1_시험_필수확인사항_브리프」 p.1은 후속 서술형 6문항·문항당 5분을 안내한다. 「3_사전_체험_및_응시환경_상세_가이드」 p.4의 5문항 화면은 예시이며, 실제 응시 화면을 확인한다. 이전 문항으로 돌아갈 수 없고 복사·붙여넣기도 사용할 수 없다.
