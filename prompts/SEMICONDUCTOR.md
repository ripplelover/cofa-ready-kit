# 반도체 검사·측정 데이터가 실제 과제에 있을 때

제공된 Codex의 **과제 수행 단계**에서 사용한다. 수율·SPC가 과제 요구와 관계없으면 해당 분석을 추가하지 않는다. 도구 실습과 정확한 명령은 [반도체 실습](../docs/SEMICONDUCTOR-WALKTHROUGH.md)에 있다.

## 먼저 의미와 적용 여부 확인

```text
$cofa-semiconductor
스킬이 검색되지 않으면 .cofa-kit/skills/cofa-semiconductor/SKILL.md를 직접 읽어 줘.
실제 README와 데이터 파일을 읽고 아래 내용을 먼저 구분해 줘.

- 한 행의 단위와 고유 키, 재검사·중복의 의미
- 검사/통과/불량 개수의 분모와 단위, 결측·0의 의미
- 설비·제품·레시피·측정 항목·단위·시간의 비교 가능성
- 요구된 결과와 실제로 확인할 수 있는 검증 기준

명시된 사실과 가정을 구분하고 계산을 바꾸는 질문만 골라 줘.
실무자에게는 내가 직접 물어볼게.
현재 과제에 이 키트의 수율 집계나 I-MR가 맞는지 먼저 판단해 줘.
맞지 않으면 실제 요구에 맞는 더 단순한 방법을 선택해 줘.
```

## 분모를 확인한 뒤 수율 집계

```text
현재 확인된 검사·통과 개수와 고유 키를 기준으로 집계해 줘.
행별 비율의 평균과 전체 개수 기준 비율을 구분하고 요구된 지표를 사용해 줘.
중복 검사 정책이 미확정이면 임의로 마지막 행을 선택하거나 합산하지 마.
키트의 semi yield가 맞으면 실제 열 이름으로 실행하고,
작은 그룹 하나를 손계산해 출력의 tested/passed/pass_rate_pct와 대조해 줘.
전체 제조 수율이나 설비 원인으로 확대 해석하지 말고 데이터 범위와 한계를 남겨 줘.
```

## 동질적인 계열과 기준 구간이 확인된 뒤 SPC

```text
실제 데이터에서 한 측정 계열인지, 시간·단위·기준 구간이 적절한지 확인해 줘.
키트의 semi spc를 쓴다면 기준 구간의 개수와 선택 이유를 명시하고
이후 관측을 기준 계산에 다시 섞지 마.
실제 존재하는 열만 series-cols로 지정해 줘.
baseline의 mean/mr_bar/관리한계와 evaluation의 I/MR 신호를 설명하고,
기준 마지막 값에서 첫 이후 관측으로 이어지는 moving range도 확인해 줘.
신호는 검토 대상으로 표현하고 제품 합격·불합격, 원인 확정, 공정능력 판정을 했다고 말하지 마.
```

## 제출 확정 전 자기 설명

```text
지금은 제출 확정 전 연습 단계야.
내가 선택한 분모, 중복 정책 또는 기준 구간 중 가장 중요한 판단 하나를 질문해 줘.
내가 먼저 답할 때까지 답안 초안을 쓰지 마.
답한 뒤에는 실제 코드·기록과 다른 부분과 검증하지 않은 주장을 지적해 줘.
```

**실제 후속 서술형에서는 AI·Skill·MCP와 복사·붙여넣기를 사용하지 않는다.** 위 요청은 실제 문항의 답을 만들기 위한 것이 아니다.
