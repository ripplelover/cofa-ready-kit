# Cofa Ready Kit maintenance

This repository contains generic preparation tools, not an exam answer or official Cofa software.
Use Python 3.10+ standard library for the core. Keep all runtime data local.
Never equate kit tests or artifact existence with successful exam functionality.
Preserve task-specific required filenames, existing code, and user changes.
Run `python -m unittest discover -s tests -v` for code changes.

When applying these tools in Cofa: the current task README and organizer rules govern.
Use only the provided Codex and its permitted models; no external AI, API keys, outbound
exam data, git push, or computer/browser automation. Follow-up written questions are
answered by the participant without AI. Practice guidance is for before that phase.
Do not copy this file over a task's existing AGENTS.md. Skill installation copies only skills.
